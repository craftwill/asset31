# Reference images

These are still frames extracted from the user-provided video **Life Inside a Planet-Sized Megastructure**. They are the primary visual source of truth for a 1:1 playable recreation: scale, architecture, lighting, atmosphere, composition, and environmental details should match as closely as practical.

- `Video_Reference_Contact_Sheet.jpg` provides a quick overview.
- `video_frames/` contains the individual frames at the timestamp in each filename.

Do not treat these as a loose mood board. Recreate the depicted world 1:1 using game-ready geometry, materials, and lighting, allowing only the technical translation required for a playable real-time scene. The only intentional visual change is reducing distracting z-fighting/depth flicker for visual comfort; preserve every other visible design choice. These extracted stills are reference images, not a license to reuse underlying video assets.
