# Environment Polish & World Cohesion

This package contains a master prompt for Gemini/Claude to guide the next development phase of the Asset31 vertical slice.

## How to use
1. Add `MASTER_PROMPT.md` to the project's root or your agent's context.
2. Start a new agent task and paste the prompt.
3. The agent must begin with **Phase 0 — Audit and baseline** and must not make broad edits before presenting its findings.
4. Review the proposed priorities, then approve the phases one at a time.

The brief intentionally puts environment polish before new major systems. The Inter-Stack Express is included as a later design phase, not an immediate implementation mandate.
